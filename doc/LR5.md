# Отчет по реализации представления и хранимой процедуры

## 1. Представление `recent_high_value_purchases`

**Описание**:  
Создано представление, которое отображает информацию о 10 последних покупках с суммой свыше 1000 рублей. Включает имя покупателя, дату покупки и общую сумму.

**Особенности**:
- Фильтрация по сумме (>1000 руб.)
- Ограничение вывода (10 последних записей)
- Сортировка по дате (новые сначала)

**Использование**:
```sql
SELECT * FROM recent_high_value_purchases;
```

## 2. Хранимая процедура `calculate_category_totals_for_customer`

**Описание**:  
Процедура рассчитывает общую сумму покупок по категориям товаров для указанного покупателя с использованием курсора.

**Особенности**:
- Принимает параметр `customer_id`
- Использует курсор для обработки данных
- Возвращает результаты, отсортированные по сумме (по убыванию)
- Обрабатывает случаи отсутствия данных

**Использование**:
```sql
CALL calculate_category_totals_for_customer(5);
```
