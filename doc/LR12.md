### Модели данных
```python
# models.py
from pydantic import BaseModel
from typing import Optional

class Category(BaseModel):
    code: int
    name: str

class Customer(BaseModel):
    id: int
    name: str

class Product(BaseModel):
    id: int
    name: str
    price: float
    category_code: int

class Purchase(BaseModel):
    id: int
    customer_id: int
    date: str
    price: float

class PurchaseItem(BaseModel):
    purchase_id: int
    product_id: int
    amount: int
    inorder_price: float
```

## 3. Тестирование API через Postman

### Эндпоинты
1. **Категории**
    - GET /api/categories - Все категории
    - GET /api/categories/{code} - Категория по коду
    - POST /api/categories - Создание
    - PUT /api/categories/{code} - Обновление
    - DELETE /api/categories/{code} - Удаление

2. **Покупатели**
    - GET /api/customers - Все покупатели
    - GET /api/customers/{id} - Покупатель по ID
    - POST /api/customers - Создание
    - PUT /api/customers/{id} - Обновление
    - DELETE /api/customers/{id} - Удаление

3. **Товары**
    - GET /api/products - Все товары
    - GET /api/products/{id} - Товар по ID
    - POST /api/products - Создание
    - PUT /api/products/{id} - Обновление
    - DELETE /api/products/{id} - Удаление

4. **Покупки**
    - GET /api/purchases - Все покупки
    - GET /api/purchases/{id} - Покупка по ID
    - POST /api/purchases - Создание
    - PUT /api/purchases/{id} - Обновление
    - DELETE /api/purchases/{id} - Удаление

5. **Позиции покупок**
    - GET /api/purchase_items - Все позиции
    - GET /api/purchase_items/{purchase_id} - Позиции по ID покупки
    - POST /api/purchase_items - Создание
    - PUT /api/purchase_items - Обновление
    - DELETE /api/purchase_items - Удаление

## 4. Запуск и тестирование

### Запуск сервиса
```bash
# Запуск FastAPI сервера
uvicorn src.app.main:app --reload
```

1. Создать коллекцию запросов
2. Импортировать эндпоинты
3. Проверить каждый эндпоинт:
    - Создание (POST)
    - Получение (GET)
    - Обновление (PUT)
    - Удаление (DELETE)
4. Проверить обработку ошибок
